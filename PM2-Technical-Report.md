**W3-PM2 – Password Cracking with NetworkWalks Tools**

**1. Module Information**

- Training Program: NetworkWalks – Cybersecurity & Ethical Hacking
- Week: 3
- Project Code: W3-PM2
- Module Title: Password Cracking with NetworkWalks Tools
- Operating System: Windows 10
- Tools: NetworkWalks Hash Calculator and Password Cracker
- Status: Successfully Completed

**2. Objective**

To recover the password of the training-provided password-protected PDF file using NetworkWalks online tools.

**3. Tools Used**

- NetworkWalks Hash Calculator
- NetworkWalks Password Cracker
- Web Browser
- PDF Reader

**4. Implementation Steps**

*Step 1: File Preparation*

Downloaded the training-provided password-protected PDF file.

*Step 2: Hash Calculator*

Opened the NetworkWalks Hash Calculator in a web browser.

*Step 3: PDF Upload*

Uploaded the protected PDF file to the Hash Calculator.

*Step 4: Hash Extraction*

Obtained the PDF hash and copied the complete hash value.

*Step 5: Password Cracker*

Opened the NetworkWalks Password Cracker.

*Step 6: Hash Submission*

Pasted the extracted hash into the Password Cracker.

*Step 7: Password Recovery*

Started the password recovery process and waited for the result.

*Step 8: Result Verification*

Used the recovered password to open the protected PDF successfully.

**5. Results**

- The PDF file was successfully uploaded.
- Hash extraction was successful.
- The complete hash was submitted to the Password Cracker.
- Password recovery was successful.
- The protected PDF was successfully opened.

**6. Learning Outcomes**

- Learned how to use online hash extraction tools.
- Practiced transferring hash data between security tools.
- Gained experience with browser-based password recovery.
- Understood the basic workflow of online password security testing.
- Verified the recovered password through practical testing.
