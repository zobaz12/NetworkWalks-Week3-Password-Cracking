**W3-PM1 – Password Cracking with John the Ripper**

**1. Module Information**

- Training Program: NetworkWalks – Cybersecurity & Ethical Hacking
- Week: 3
- Project Code: W3-PM1
- Module Title: Password Cracking with JTR
- Operating System: Windows 10
- Tools: John the Ripper and Johnny GUI
- Status: Successfully Completed

**2. Objective**

To recover the password of the training-provided password-protected PDF file using John the Ripper and Johnny GUI.

**3. Tools Used**

- John the Ripper (JTR)
- Johnny GUI
- PDF Hash Extraction Tool
- Windows Notepad
- PDF Reader

**4. Implementation Steps**

*Step 1: Environment Preparation*

Downloaded and extracted John the Ripper on the Windows computer.

*Step 2: John the Ripper Verification*

Located the John executable and verified that the tool was available.

*Step 3: Johnny GUI Installation*

Downloaded and installed Johnny GUI.

*Step 4: Configuration*

Configured Johnny by specifying the location of the John executable.

*Step 5: PDF Hash Extraction*

Uploaded the training PDF to the PDF hash extraction tool and obtained the password-related hash.

*Step 6: Hash File Preparation*

Copied the extracted hash into Notepad and saved it as "hash1.txt".

*Step 7: Hash Loading*

Opened Johnny and loaded the prepared hash file.

*Step 8: Password Recovery*

Started the password recovery test and waited for the result.

*Step 9: Result Verification*

Used the recovered password to open the protected PDF successfully.

**5. Results**

- John the Ripper was successfully prepared.
- Johnny GUI was successfully installed and configured.
- PDF hash extraction was completed.
- The extracted hash was successfully loaded into Johnny.
- Password recovery was successful.
- The protected PDF was successfully opened.

**6. Learning Outcomes**

- Gained practical experience with John the Ripper.
- Learned how to configure Johnny GUI.

- Understood the basic password recovery workflow.
- Verified the results through practical testing.
